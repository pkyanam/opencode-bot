# Project website

Static GitHub Pages site at https://pkyanam.github.io/opencode-bot/.
No framework, build step, external fonts, analytics, or runtime dependencies.

Preview: `python3 -m http.server 8844 --directory site`

Changes to `site/` on main publish through `.github/workflows/pages.yml`.
The workspace illustration is explicitly an example, not a live application.
Keep feature claims aligned with the root README and label preview features.

Assets: `wordmark.png` is the existing project wordmark from
`apps/web/public/brand/`. `opencode.png` is OpenCode's official favicon,
retrieved from https://opencode.ai/favicon-96x96-v3.png, used for attribution.
OpenCode Bot is independent of OpenCode; upstream branding is not covered by
this project's MIT license.
